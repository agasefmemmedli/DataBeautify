Dockerfile (Dockerfile) — инструкции сборки контейнеров.

Shell Script (.sh) — скрипты Bash/Zsh.

PowerShell (.ps1) — автоматизация в Windows.

Terraform / HCL (.tf, .tfvars) — инфраструктура как код.

Makefile (Makefile) — автоматизация сборки.

Nginx Config (.conf, .nginx) — настройки серверов.

SQL (.sql) — структурированные запросы.

Prisma (.prisma) — схемы баз данных.

MongoDB Shell (.mongodb) — скрипты для NoSQL.

Markdown (.md) — README и документация.

MDX (.mdx) — Markdown с компонентами React.

LaTeX (.tex) — научные статьи и формулы.

Log Files (.log) — просмотр логов (форматирование по датам/уровням).

Handlebars (.hbs) — шаблоны.

Twig (.twig) — шаблоны PHP.

Liquid (.liquid) — шаблоны Shopify/Jekyll.

Jupyter Notebook (.ipynb) — JSON-структура тетрадок Python.

SVG (.svg) — по сути XML, но часто требует специфического сжатия/очистки.

Git Config (.gitconfig) — локальные настройки Git.

EditorConfig (.editorconfig) — правила форматирования проекта.

Astro (.astro) — современный фреймворк для контента.
